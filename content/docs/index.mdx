HaloKYC is a hosted identity-verification flow and developer API. Your server creates a session, your user completes the required checks, and your product receives a final status.

<Callout type="info" title="The recommended integration">
  Create sessions from your backend and redirect users to the HaloKYC hosted flow. Never expose an API key in browser code.
</Callout>

## How the pieces fit

<Steps>
  <Step>
    ### Your backend starts a session

    Send an `external_user_id`, a `workflow_id`, and an optional HTTPS callback URL using your workspace API key.
  </Step>
  <Step>
    ### Your product redirects the user

    Open `/verify?verification_id=<uuid>` on your HaloKYC frontend. The session ID is the bearer credential for the public capture flow.
  </Step>
  <Step>
    ### HaloKYC runs the workflow

    Depending on the workflow, HaloKYC captures identity documents and a selfie, then performs document, face, liveness, age, and duplicate checks.
  </Step>
  <Step>
    ### Your server consumes the decision

    Use the webhook as a notification, then fetch or reconcile the session status before changing a sensitive entitlement.
  </Step>
</Steps>
